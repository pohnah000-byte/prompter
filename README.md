# Суфлёр

Телесуфлёр для iPhone, который работает прямо в браузере: без подписки, рекламы и водяных знаков.

**Открыть:** https://pohnah000-byte.github.io/prompter/

## Что умеет

- Текст бежит под камерой — по темпу (слова в минуту) или **по голосу**: едет, пока говоришь, и ждёт, когда молчишь
- Запись видео и **фото** с фронтальной или основной камеры
- Форматы кадра **9:16, 1:1, 16:9**
- **Зеркало** для сохранённых видео и фото
- Сохранение в Фото через «Поделиться» → «Сохранить видео»
- Сценарии, дубли и настройки хранятся только на телефоне

## Как поставить на экран «Домой»

1. Открой ссылку в Safari на iPhone
2. Нажми «Поделиться» → «На экран „Домой“»
3. При первом запуске разреши камеру и микрофон

Для режима «По голосу» включи Siri и диктовку в Настройках iPhone; нужен интернет.
